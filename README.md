# 🏅 2026 佛光山台北道場｜為考生祈福禮 電子邀請卡

這是一個單頁式互動電子邀請卡專案（Static HTML + Tailwind CSS），所有圖片素材（主視覺海報、報名 QR Code）均已透過 Base64 內嵌於 `index.html` 中，可直接部署至 **GitHub Pages**、**Vercel** 或 **Netlify**。

- **考生對象**：國中、高中(職)、大學及各級考生
- **立即報名**：https://reurl.cc/8YRZVy
- **宣傳影片**：https://www.youtube.com/watch?v=8z_dv6ElMLc

## 🚀 部署方式
1. 將 `index.html` 與 `vercel.json` 上傳至 GitHub Repository 根目錄。
2. 前往 [Vercel New Project](https://vercel.com/new) 匯入該 GitHub Repository，點擊 **Deploy** 即可完成發布。
